WatchWin Android Demo Project

এই project একটি Android WebView wrapper, যার ভিতরে WatchWin-এর demo UI চলছে।
বাস্তব টাকা দেওয়ার অ্যাপ নয়।

Build:
1. Android Studio-তে project folder open করো।
2. Gradle sync শেষ হতে দাও।
3. Build > Build APK(s) নির্বাচন করো।

বাস্তব অ্যাপে পরে authentication, backend/database, approved rewarded ads,
anti-fraud এবং বৈধ payment integration প্রয়োজন।
